# Идея компании
**Название:** PetAssist

**Что делаем:** сервис ухода за домашними животными. Это платформа, с помощью которой владельцы питомцев могут найти проверенных специалистов для выгула, груминга, передержки, домашнего присмотра, ветеринарных услуг. Главное наше преимущество в том, что в России есть популярные сервисы конкретно для выгула/петситтеров, для груминга и т.д., но нет площадки, где собраны все необходимые услуги.
